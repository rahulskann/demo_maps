# demo_maps

Map packs for [TOME](https://github.com/rahulskann/tome), one folder per game.
Kept separate from the TOME repo because they contain third-party game art.

| Folder | Game |
| --- | --- |
| [`silksong/`](silksong/) | Hollow Knight: Silksong |

Install a pack on a phone running a debug build of TOME:

    python ../tome/tools/sideload_pack.py silksong
